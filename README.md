## Brief — what this week is

You are **not** shipping a new system. You **audit** what you already built, **name** real understanding gaps under cohort-voted topics, **pair** daily with a colleague (morning + evening calls), **research** each other’s question (≥2 primary sources + hands-on tool/pattern), and **publish** a blog + thread under your identity. Each cycle ends with a **grounding change** to existing Week 10/11 work so the week pays back into your portfolio.
